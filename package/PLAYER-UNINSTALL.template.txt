Supported Cyberpunk 2077 version: {{GAME_VERSION}}

BEFORE UNINSTALLING
1. Close Cyberpunk 2077.
2. Read the release notes for this exact realpass version.
3. Follow any version-specific migration or compatibility instructions before
   removing files. RealPass does not create or require its own save-backup step.

UNINSTALL RULE
Remove only files owned by this realpass build as listed in:

    realpass/build-manifest.json

Do NOT delete broad shared directories such as r6/scripts, red4ext/plugins,
archive/pc/mod, or r6/tweaks. Other mods may use them.

FRAMEWORK DEPENDENCIES
A framework file marked "approved-dependency-owned" in the build manifest may
also be used by another installed mod. Do not blindly remove shared framework
files just because realpass bundled them. The final release helper must either:

- detect that the dependency is still shared/needed and leave it in place; or
- explain that manual dependency removal is optional and separate from removing
  realpass-owned gameplay files.

SAVE STATE
Removing files does not itself prove that a persistent gameplay schema is
compatible with an older/newer RealPass build. Follow the exact release's
migration/uninstall procedure when persistent-state compatibility matters. Do
not invent a generic save-backup/restore workflow.

SAFE HELPER
If this release contains an uninstall helper, it must be finite and
user-invoked. It may delete only paths/hashes owned by the exact build manifest
and must fail closed if a supposedly owned file has drifted. It must not install
or use a background service, watcher, scheduled task, or permanent launcher.
