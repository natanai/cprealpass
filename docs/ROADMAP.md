# realpass roadmap

1. **Presentation and body acceptance.** Verify realpass naming, unclipped needs, E3 focus names, scanner/dialogue transitions, food/drink absorption, exertion, wait/sleep, bathroom/washing and save/reload in one combined session.
2. **Timing and calibration.** Measure the native game clock, menu/lifecycle boundaries, scripted jumps and long skips. Tune daily resource use and fatigue against the applied game behavior.
3. **Injury and treatment.** Complete blood-loss attribution and timing, critical skip behavior, clinical care, treatment presentation and remaining equipment coverage. Activate the existing regional combat/treatment modules as a coherent later candidate.
4. **Gameplay compatibility.** Validate V/NPC behavior, bosses, authored immunity, nonlethal outcomes, performance and quest-critical Phantom Liberty sequences.
5. **World and distribution.** Add useful clothing, economy, transport and apartment interactions after the core milestone. Finish reproducible acquisition/bootstrap, permitted packaging, updates and recovery. Weather control is optional.

Implemented models and compiled scripts are progress, but native behavior remains an acceptance requirement. Prefer large, useful playtest batches over repeated individual checks.
