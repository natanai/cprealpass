# Biology E3 component mapping

Status: attended follow-up design-archaeology contract  
Last updated: 2026-09-15  
Issue: #40

## Purpose

The attended `8cf04566...` Biology candidate proved that a small red biomonitor frame plus a nameplate decoration is not enough to make ordinary gameplay read as the intended red/minimal 2018/E3-inspired presentation. This document prevents future work from collapsing the E3 target back to those two surfaces.

Project E3 HUD is **reference material only**. Biology must not execute or redistribute its archive, scripts, tweak payload, settings implementation, or save/runtime authority. The supported final implementation must be Biology-owned and preserve Cyberpunk 2077's current scanner/quickhack experience.

The durable reference inventory remains `config/realpass-e3.json`. For this follow-up, the complete user-supplied Project E3 `2.31.p2` reference ZIP was inspected locally outside Git and every manifest-listed script/tweak/archive payload checked matched the recorded byte length and SHA-256. No Project E3 source body is added to this repository.

## Design rule

For every reference area below, the question is not “copy this Project E3 file.” The question is:

> What visible responsibility made the 2018/E3 composition coherent, what current 2.31 native controller still owns the authoritative game information, and what is the narrowest Biology-owned presentation seam that can reproduce the materially important visual language without stealing gameplay/scanner authority?

`E3 OFF` always means the Biology-owned E3-specific treatment yields. It does **not** change Biology simulation and does **not** restore actor HP bars while Biology itself remains enabled.

## Nameplate knowledge model

Biology does not maintain a second NPC identity database.

The intended precedence is:

1. **Native focus/nameplate identity already supplied in `NPCNextToTheCrosshair.name` wins.** This covers identities the game already knows/chooses to expose.
2. If that is empty and the target is an ordinary public crowd identity whose native `UiNameplate()` record permits a name, Biology may use the entity's public `GameObject.GetDisplayName()` for the baseline E3 ambient nameplate.
3. Authored hidden names, alternative identities, `hide_nametag`, dynamic `Puppet.HideNameplate`, disabled nameplate records, and quest-specific policy are not overridden by the generic crowd fallback.
4. When scanning causes native focus/nameplate data to become richer, that native supplied value moves to step 1 automatically and therefore enriches the ordinary post-scan E3 nameplate without a Biology-owned knowledge store.

The baseline ambient presentation is therefore **not scanner-gated**, while scanner-acquired knowledge can still enrich it.

## Modern scanner exclusion

The scanner boundary is deliberately stronger than “we did not notice a scanner bug.” Biology presentation code must not hook or replace scanner/quickhack controllers or load scanner/quickhack/focus-mode resources. The historical `config/patches/realpass-modern-scanner.json` remains provenance showing which Project E3 resources had to be omitted during the old integration; it is not a recipe for the final Biology package.

## Follow-up implementation set

Issue #40 should now treat the ordinary HUD as a coordinated set of surfaces rather than a single biomonitor widget. The minimum implementation set for the next attended candidate is:

- global HUD composition / red framing;
- quest/objective tracker;
- navigation/minimap integration;
- weapon/ammo roster;
- ordinary interactions/prompts and dialogue-choice presentation;
- activity log;
- restrained crosshair and D-pad styling where active;
- ambient NPC identity/nameplate visibility and styling;
- unchanged Biology-wide barless-health policy;
- unchanged native modern scanner/quickhack presentation.

A component can remain native only when the table above gives a reason that retaining it does not leave ordinary gameplay visually dominated by the retail HUD.
