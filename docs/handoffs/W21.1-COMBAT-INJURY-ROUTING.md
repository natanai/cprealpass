### First broken boundary — combat profile readiness

`CRCombatProfilesNative.Read` enumerates the player's equipped clothing areas
and all cyberware equipment areas. Before W21.1, `AddProtection` treated an
otherwise-valid equipped record with no `CRStockProtectionCatalog` mapping as
the same fatal `unresolvedProtection` state as a malformed equipment/read
failure.

That made:

`sample.referenceReady = sample.unresolvedProtection == 0 && ValidState(...)`

false whenever any visited equipped item lacked a Biology protection mapping.
`CRNativeWoundBridge.Prepare` rejects that state before creating
`crWoundPlan` or replacing the physical channel. Native Cyberpunk therefore
continues its ordinary damage/resource path and Health can visibly decrease,
while Biology has no plan to commit in `SendDamageEvents`. This is the first
static boundary in the requested chain that directly explains T005-F04 while
preserving the observed healthy runtime.

### Minimal repair

W21.1 now separates:
- structural/equipment-read failure: still `unresolvedProtection`, fatal;
- valid but unmapped protection record: `unmappedProtection`, bounded;
- NPC unmapped appearance protection: still fail-closed;
- player unmapped protection: eligible only through a conservative native cap.

For the player-only unmapped path, `Prepare` retains the full causal ballistic
wound proposal in the plan but applies:

`min(Biology proposed physical, already-computed native physical)`

to the physical channel. It never raises damage above the native result when
protection is unknown. After native one-shot/boss/resource handling,
`Commit` still requires actual physical Health loss. The existing
`finalPhysical / proposedPhysical` acceptance ratio proportionally constrains
the wound before `CRBodyRuntime.RecordInjury`.

This preserves:
- native Health/resource authority;
- native protection/difficulty reductions as a conservative ceiling when Biology
  lacks a player protection map;
- native one-shot/boss semantics;
- causal hit -> wound -> body-input routing;
- no Health polling, timers, synthetic wounds, or second damage authority.

Bounded per-hit plan evidence records whether the native cap was used and the
pre-Prepare native physical value. No global hit history was added.
