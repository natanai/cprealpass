## Source diagnosis

On the reverted baseline, player authority was:

`CRBodyRuntime.NativeStateAllowed`
→ `CRInjuryEffectsBridge.Allowed(player, true)`

`CRInjuryEffectsBridge.Allowed` is a generic actor/NPC impairment eligibility helper. It rejects detached/dead/defeated/replacer actors **and** actors for which the native SceneSystem reports `IsEntityInScene`.

That generic decision was reused as the player body's ownership/lifecycle decision.

The same `NativeStateAllowed` result gates:

1. ordinary `CRClockModel.Observe` progression;
2. `CRBodyRuntime.Consume` before a native consumable can enter `CRBodyInputs.Intake`;
3. `CRBodyRuntime.CanAcceptCombatInjury` before `RecordInjury`.

Therefore a single false player decision can produce exactly the systemic shape seen in T007: scheduler alive, body time frozen, consumables rejected before model ingestion, and combat stopped at `commit-body-gate`.

The body model itself was not the first broken boundary. Existing tests already exercise its water/energy/urine/bladder, sleep, exertion, injury and ordered-input equations.

### Player-specific lifecycle

`CRPlayerBodyLifecycle.Allowed(player, allowMenu)` is now the one player eligibility adapter.

A player is eligible only when:

- Biology launcher activation is enabled;
- the player exists;
- the player is attached;
- the player is not a replacer;
- the player is alive and not defeated.

For ordinary body time/combat/effects, it additionally requires:

- UI is not in a menu;
- native TimeSystem is not paused.

For a completed native intake/body action, callers may use `allowMenu=true`. This is not manufactured physiology: the stock game action has already completed, and the menu may itself be the reason gameplay is paused.

### What is intentionally *not* a player authority gate

W21.4 does not reuse NPC `SceneSystem.IsEntityInScene` as player body ownership.

It also does not adopt the rejected autonomous PR #153's strict `PlayerStateMachine.HighLevel` scene-tier whitelist. That implementation exact-compiled but remained live-unaccepted, and no current attended evidence proves such a tier whitelist is the correct physiology predicate.

A dialogue/cinematic scene is not automatically equivalent to a physiological pause. Menu/pause state is the explicit ordinary-progression boundary here.
