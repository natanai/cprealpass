## Native/source diagnosis

W17.1 current-2.31 archaeology remains authoritative for structure:

`Inventory / RipperdocInventoryController -> cyberwareContainer -> GridAndSlider -> grid -> scrollRect -> virtualGridContainer`

Biology correctly remains a sibling of the authored `cyberwareContainer` under
`Inventory`; W19.1 does not return to `virtualGridContainer`.

The important lifecycle fact is that `DisplayInventory(false)` owns the native
Inventory close/opacity/hide transition. The T005 implementation restored the captured
`cyberwareContainer` visibility as part of
`CRSetBiologyDetailSurface(false)` before native close had completed. Merely swapping
the two synchronous calls would still make stock content eligible to render during the
native hide/fade lifecycle.

Therefore stock-content visibility is not detail-depth state. It is **mode ownership**:

- Biology mode owns suppression of the authored `cyberwareContainer`;
- Biology detail activation marks detail active and ensures suppression before
  `DisplayInventory(true)`;
- Biology Back calls native `DisplayInventory(false)` while the stock child remains
  suppressed, then clears only Biology's detail marker;
- Biology overview continues to own suppression;
- deliberate switch to Cyberware restores the exact visibility captured when Biology
  took ownership;
- screen teardown also restores captured stock visibility defensively.

This keeps native zoom/show/hide authority intact without a timer, frame callback, sleep,
delay, or screenshot-derived compensation.
