### T005-F03 — identity authority

The previous wrapper copied `NPCNextToTheCrosshair`, filled an empty `data.name` with Biology's public `GetDisplayName()` fallback, and then called native `SetVisualData`.

W20.1 removes that mutation. It preserves the exact wrapper call shape already compiled/tested in the T005 candidate:

`let data = Deref(incomingData) -> wrappedMethod(puppet, data, isNewNpc)`

but `data` is now unmodified.

The fallback remains presentation-only in `CRRefreshBiologyE3Nameplate`, after native `SetElementVisibility` handling. Native `data.name` still wins whenever present.

Required direction is now enforced in tests:

`native discovered identity -> native nameplate/scanner authority -> Biology ambient presentation`

never:

`Biology GetDisplayName fallback -> native SetVisualData / scanner knowledge`.
