## Goal

Make third-party reference mods a first-class private engineering-evidence source without making Biology depend on them or committing/redistributing their payloads.

The owner has a persistent local library at:

`C:\Games\Cyberpunk-ReferenceMods`

It currently contains Project E3 HUD/UI material and may gain other example mods and dependencies later.

## Required owner UX

Create one repository-owned read-only workflow that lets the owner select one or more reference folders and returns **one obvious attachable private handoff bundle** for a worker conversation.

The normal owner interaction should be one command or thin launcher, not a hand-written PowerShell chain.

The command must:
- support zero local cprealpass repo state using the project's exact-source bootstrap conventions;
- never install the reference mod into Cyberpunk merely to inspect it;
- never mutate/delete the source reference library;
- identify selected folder names, provenance/version notes when discoverable, file tree, sizes, SHA-256, and dependency/readme metadata;
- include useful text/source/config files for private worker analysis;
- avoid duplicate inclusion when both a downloaded ZIP and its extracted folder are present;
- inventory binary/archive/resource files and clearly state whether their contents were actually inspectable;
- use an available safe archive/resource listing tool when already present and useful; otherwise fail transparently on that sub-capability rather than inventing an interpretation;
- produce one private ZIP marked as third-party reference material for analysis only;
- print one clear `ATTACH THIS ONE REFERENCE BUNDLE TO CHATGPT` path.

Do not upload the third-party contents to GitHub.

## Durable repo output

Add a safe derived reference-record format that workers can populate after analysis, containing only:
- source mod/version/provenance;
- selected hashes/path identities;
- dependency/framework roles;
- derived native-controller/widget/resource mappings;
- Biology-owned conclusions.

No third-party implementation bodies or proprietary game payload belong in Git.

## Worker request convention

Update active worker guidance so when an existing mature mod plausibly solves the same subsystem, workers explicitly consider requesting a reference bundle before another speculative native probe or attended cycle.

A request should state:
- the reference mod/dependencies wanted;
- why it is relevant;
- what exact uncertainty the worker expects it to resolve.

## Immediate acceptance

The workflow must be usable for the owner's Project E3 HUD/UI folders under `C:\Games\Cyberpunk-ReferenceMods`.

It should create a private bundle suitable for W03.7 to inspect script/config/resource provenance and identify what remains opaque (for example archive internals if no safe local inventory tool is available).

## Non-goals

- no Biology gameplay/UI implementation;
- no installing Project E3;
- no runtime dependency changes;
- no redistribution of third-party payload through GitHub;
- no asking the owner to play a worker branch;
- do not merge your own PR.

Return READY-PARENT with exact branch head, CI, command name, and one concise owner invocation pattern.
